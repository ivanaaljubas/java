Java – Laboratorijske vježbe

Repozitorij sadrži laboratorijske vježbe iz kolegija **Programiranje u Javi**. 
## Stečene vještine
- Osnove sintakse Jave i rad s osnovnim tipovima podataka
- Korištenje petlji, grananja, metoda i nizova
- Rad s klasama, objektima i konstruktorskim metodama
- Principi **objektno orijentiranog programiranja (OOP)**:
  - Enkapsulacija
  - Nasljeđivanje
  - Polimorfizam
- Korištenje apstraktnih klasa i sučelja (interfejsa)
- Obrada iznimki
- Rad s kolekcijama
- Osnove rada s datotekama
